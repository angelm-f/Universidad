
# Sistema web de lavado de vehículos

## Descripción
Proyecto académico para administrar los servicios y las
órdenes de un negocio de lavado de vehículos.

## Primer avance
- Análisis del problema y objetivos.
- Diseño de la base de datos.
- Creación de tablas en PostgreSQL.
- Maqueta inicial de la página web.

## Tecnologías previstas
- Java
- Maven
- PostgreSQL
- HTML y CSS
- HTTP y JSON
- API REST

## Ejecución de la maqueta
Abrir el archivo web/index.html en un navegador.

## Estado del proyecto
Primer avance: diseño inicial y base de datos.
