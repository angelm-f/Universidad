# Tarea VII - PostgreSQL Inventario

## Descripción

Base de datos desarrollada en PostgreSQL para controlar el inventario
básico de una tienda.

## Base de datos

control_inventario

## Requisitos

- PostgreSQL
- pgAdmin 4

## Orden de ejecución

1. database/01_creacion.sql
2. database/02_datos_prueba.sql
3. database/03_operaciones.sql

## Estructura

- 01_creacion.sql: creación de la base de datos, tabla y restricciones.
- 02_datos_prueba.sql: inserción de productos y pruebas de restricciones.
- 03_operaciones.sql: consultas, actualizaciones y eliminación.
