# Sistema de Envíos

## Descripción

Aplicación de consola desarrollada en Java que permite registrar envíos nacionales e internacionales y calcular su costo final según las características de cada envío.

## Objetivo

Aplicar conceptos de Programación Orientada a Objetos como clases, objetos, encapsulamiento, constructores, herencia, sobrescritura, sobrecarga y polimorfismo.

## Temas aplicados

* Clases y objetos.
* Atributos y métodos.
* Encapsulamiento.
* Constructores.
* Herencia.
* Sobrescritura de métodos.
* Sobrecarga de métodos.
* Polimorfismo.
* Validación de datos.
* Estructuras condicionales.
* Estructuras repetitivas.

## Instrucciones para ejecutar el programa

1. Abrir el proyecto en IntelliJ IDEA.
2. Abrir el archivo `Main.java`.
3. Ejecutar el método `main`.
4. Seleccionar una opción del menú.
5. Ingresar los datos solicitados.
6. El programa calculará y mostrará el costo correspondiente.

## Resultado esperado

El programa permite registrar envíos nacionales e internacionales, calcular su costo final y mostrar un resumen con el desglose de los costos.

Para un envío nacional de 5 kg y 120 km se espera un costo final de **Q110.00**.

Para un envío internacional de 3 kg se espera un costo final de **Q108.60**.
